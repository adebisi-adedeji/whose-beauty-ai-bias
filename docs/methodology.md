# Methodology

## Research Question

Does the presence of a country label change the type and frequency of social, cultural, occupational, and personality inferences generated by a multimodal vision-language model when the underlying portrait image is held constant?

## Overview

This study uses Gemini 3.5 Flash to generate free-text descriptions of ten screened portrait images under five conditions: a no-metadata control, and four country conditions (Nigeria, India, Saudi Arabia, United Kingdom). Control and country-conditioned prompts are matched to differ *only* in the presence of the country name, eliminating confounds from prompt wording. Each image is generated three times per condition, producing 150 total responses.

Generated responses are decomposed into individual statements and classified under a statement-level evidence-grounding protocol (see `annotation_protocol.md`) as visually supported description, unsupported inference, or hallucination. Statistical analysis uses the Friedman test (repeated-measures, non-parametric) across the five conditions, with the image as the independent experimental unit (n=9 for the main analysis).

## Key Design Decisions

- **Single model, single prompt template**: scope frozen early to prioritise annotation depth and rigour over scale.
- **Matched prompts**: an early version of this pipeline used prompts that differed in more than just the country label; this was identified and corrected before the final run (see the dissertation's Methodology chapter for the full audit).
- **Image-level statistical unit**: repeated generations from the same image are not independent observations, so all inferential statistics are computed at the image level, not the response level.
- **Stochasticity baseline**: a permanent pipeline component comparing repeated same-prompt generations, to distinguish genuine condition effects from ordinary generation variability (see `stochasticity_baseline.md`).
