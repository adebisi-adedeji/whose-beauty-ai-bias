# Report Summary

The full dissertation report is submitted separately as the primary written deliverable for this project (MSc Data Science, Middlesex University London, module CST4990). This document provides a brief summary; see the submitted dissertation PDF for the complete account.

## Title

Geographic Metadata and Inference Bias in Multimodal AI Image Descriptions

## Research Question

Does the presence of a country label change the type and frequency of social, cultural, occupational, and personality inferences generated by a multimodal vision-language model when the underlying portrait image is held constant?

## Summary of Findings

No statistically significant effect of country condition was found across four primary outcomes (inference presence, substantive social/cultural inference, metadata repetition, visually unsupported inference; all p > 0.05, Friedman tests). A post-hoc power analysis showed the study was substantially underpowered (maximum ~18.6% power for even a large effect at n=9 images), so this null result is interpreted as inconclusive rather than as evidence of no effect.

This null result stands in contrast to an earlier, methodologically flawed pilot, which found significant effects under an unmatched prompt design and an invalid annotation measure. The corrected study's null finding, once both issues were identified and fixed, is itself a central finding: it demonstrates how a prompt confound and a measurement-validity problem can jointly produce a plausible-looking but artefactual result.

Two qualitative patterns recurred in the annotated data:
- The model repeatedly overstated hair length across different images, conditions, and repeats (at least six confirmed instances).
- On the borderline image (flagged for a visible cultural cue and excluded from the main analysis), garment recognition remained accurate across every sampled condition, including where the supplied country label directly conflicted with the visible garment.

## Contributions

1. **Empirical** — the first controlled investigation of this specific configuration (a real, fixed portrait image with only a textual country label varied), to the best of the literature search conducted.
2. **Methodological** — a reusable, statement-level evidence-grounding annotation protocol, validated to near-perfect inter-rater reliability.
3. **Evidential** — a demonstration, using this project's own data, of how prompt and measurement confounds can manufacture plausible-looking but artefactual bias findings.
