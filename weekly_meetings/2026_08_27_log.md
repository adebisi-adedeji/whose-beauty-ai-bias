### Main focus this week

Following the feedback from the previous supervision meeting, I focused this week on correcting the methodological limitations identified in the pilot and preparing a cleaner final experimental design before scaling the study.

The main objective was to ensure that the final experiment can isolate geographic metadata more reliably, strengthen the visual-evidence validation procedure, and clearly separate the primary outcomes from the exploratory analyses used in the pilot.

### 1. Final research question

I narrowed and locked the research question to:

> **Does geographic metadata change the probability and type of social, cultural, occupational, or personality inferences generated by a multimodal model when the same portrait image is held constant?**

This replaces the broader beauty-bias framing and makes geographic metadata the main experimental variable.

### 2. Corrected matched prompt design

I audited the original pilot prompts and confirmed that the control and country-conditioned prompts were not structurally equivalent. The country-conditioned prompts contained additional instructions, meaning that differences observed in the pilot could not confidently be attributed to the country metadata alone.

I therefore created corrected V2 prompt templates for the final experiment. The control and country-conditioned versions now use the same instructions, response structure and behavioural rules, with geographic metadata as the intended experimental difference.

I also added rendered-prompt verification in the notebook so that the actual prompt sent under each condition can be inspected before final generation.

The original pilot outputs have been retained unchanged rather than regenerated retrospectively, so the methodological limitation of the pilot remains transparent.

### 3. Final generation configuration and logging structure

I prepared the final generation script and reproducibility structure for the corrected experiment.

The pipeline is designed to record:

* image ID;
* experimental condition;
* repeat number;
* exact model identifier;
* prompt used;
* generation date;
* generation parameters;
* maximum output tokens;
* raw model output;
* API errors; and
* retry information.

The final generation script has been prepared but has not yet been executed because API credits are currently unavailable.

### 4. Image dataset screening and final decision

I manually reviewed all **10 pilot portraits** using explicit screening criteria for cultural, religious, national and contextual cues.

The resulting dataset decision is:

* **9 portraits** retained as the culturally neutral main-analysis set.
* **1 portrait (`vietnamcows`)** treated as a borderline case and separated for a robustness/sensitivity analysis.

### 5. Audit of the existing pilot dataset

I verified the structure and completeness of the existing pilot dataset:

**10 images × 5 experimental conditions × 3 repeated generations = 150 model responses.**

The existing dataset is retained as pilot evidence rather than being treated as the final experiment because of the original prompt-comparability limitation.

### 6. Audit of the original unsupported-inference measure

I revisited the original `unsupported_inference` variable and found that it effectively represented whether the model populated one or more structured inference fields rather than whether those inferences were genuinely unsupported by the portrait.

I therefore separated **inference presence** from **visually unsupported inference** in the revised methodology. Claims are no longer treated as visually unsupported without being checked against the source image.

### 7. Expanded statement-level annotation dataset

The original description outputs produced **363 statement-level units**.

I expanded the annotation pool beyond descriptions to include all relevant inference fields:

* **363** description statements
* **145** social/cultural inference statements
* **69** occupation inference statements
* **270** personality inference statements

This produced **847 candidate statements** for visual-evidence validation.

### 8. Revised visual-evidence annotation framework

I developed a stronger annotation framework separating analytical category from visual evidence.

Analytical categories:

* Visible description
* Visually supported interpretation
* Metadata repetition
* Unsupported social inference
* Incorrect visual hallucination

Evidence labels:

* Supported
* Unsupported
* Uncertain

This prevents metadata repetition, unsupported social inference and genuine visual hallucination from being treated as the same phenomenon.

### 9. Completed stronger 35-case manual validation

I created a new **35-statement stratified validation sample** drawn from different output fields and manually checked all **35/35 statements against their corresponding portraits**.

The completed evidence labels were:

* **21 Supported**
* **12 Uncertain**
* **2 Unsupported**

The analytical categories were:

* **10 Visible descriptions**
* **10 Visually supported interpretations**
* **9 Unsupported social inferences**
* **5 Metadata repetitions**
* **1 Incorrect visual hallucination**

This addresses the limitation of the earlier 25-statement feasibility sample, in which all sampled statements were labelled as supported.

### 10. Social/cultural inference refinement

I extracted and classified **145 individual social/cultural claims** from the pilot outputs.

After manually reviewing the ambiguous cases, there were **no unresolved manual-review cases remaining**.

The final classification was:

* **89 metadata repetitions (61.4%)**
* **32 substantive inferences (22.1%)**
* **24 mixed claims (16.6%)**

I then created a revised response-level measure of **substantive social/cultural inference**, separating genuine additional inference from repetition of metadata supplied in the prompt.

### 11. Statistical analysis of pilot inference outcomes

I applied the revised inference measures to the existing pilot data and examined social/cultural, occupational and personality inference patterns.

The analysis included:

* response-level inference rates;
* image-level aggregation;
* Friedman repeated-measures tests; and
* paired country-versus-control Wilcoxon comparisons.

These results are treated as exploratory pilot findings rather than causal evidence because the original pilot prompt design was confounded.

### 12. Repeated-generation consistency

I examined whether inference patterns were consistent across the three repeated generations for each image-condition combination.

This provides a way of distinguishing recurring inference patterns from observations appearing only in individual stochastic generations.

### 13. Semantic-shift analysis and stochasticity baseline

I compared country-conditioned descriptions with their corresponding control descriptions using matched image/repeat comparisons.

I also constructed a same-prompt stochasticity baseline to assess whether country-conditioned semantic differences were larger than normal variation between repeated model generations.

The pilot did not provide sufficient evidence that the observed semantic shift was distinguishable from normal generation variability. Semantic shift has therefore been retained as a **secondary analysis**.

### 14. Adjective-analysis audit

I audited the predefined adjective taxonomy against the actual adjective vocabulary in the pilot outputs.

The predefined taxonomy covered approximately **29.1% of observed adjective tokens**.

Adjective framing has therefore also been retained as a **secondary/exploratory analysis** rather than a primary scientific outcome.

### 15. Primary outcomes for the final experiment

The primary outcomes have now been prioritised as:

1. **Inference presence**
2. **Substantive social/cultural inference**
3. **Metadata repetition**
4. **Visually unsupported inference**

Occupation and personality inference will additionally be examined as specific forms of interpretive inference.

Semantic shift and adjective framing will remain secondary analyses.
