### Progress this week

Following feedback from the previous supervision meeting, I focused this week on refining and validating the methodology before scaling the experiment.

The final research direction has now been narrowed to examine whether geographic metadata changes the probability and type of social, cultural, occupational or personality inferences generated by a multimodal model when the same portrait image is held constant.

A major issue identified in the pilot was that the original control and country-conditioned prompts were not fully comparable. The country-conditioned prompt contained additional instructions that were absent from the control condition, meaning that differences in the pilot outputs could not be attributed solely to geographic metadata. I therefore audited the original prompts and created corrected prompt templates in which the instructions, JSON structure and behavioural rules are identical across conditions. The only experimental difference in the revised design is the presence or absence of the supplied country metadata. The original pilot responses have been retained unchanged for transparency and reproducibility.

I also strengthened the image-selection procedure following the feedback about culturally diagnostic visual cues. All 10 pilot portraits were manually reviewed using explicit criteria covering traditional or culturally diagnostic clothing, religious symbols, national identifiers and contextual cues. Nine portraits were classified as suitable for the culturally neutral main analysis. One borderline portrait was separated from the primary dataset and designated for a sensitivity/robustness analysis because its clothing could potentially provide culturally diagnostic information. The screening criteria were also expanded to consider potentially informative tattoos, jewellery, symbols and accessories.

The visual-evidence annotation protocol was further developed to distinguish between visible description, visually supported interpretation, metadata repetition, unsupported social inference, visual hallucination and uncertain cases. I completed a stronger manual validation sample of 35 statements. All 35 statements now have evidence labels and analytical categories. The evidence-label distribution contains 21 Supported, 12 Uncertain and 2 Unsupported cases, meaning that the revised validation sample now contains both straightforward and difficult cases rather than only visually supported statements.

The social/cultural inference measure was also refined. Individual claims are now separated into metadata repetition, substantive social/cultural inference and mixed claims. This prevents simple repetition of a supplied country label from being incorrectly counted as a new cultural inference. In the pilot dataset, 145 social/cultural claims were manually classified using this framework.

The primary outcomes for the final study have now been clarified as:

* inference presence;
* substantive social/cultural inference;
* metadata repetition; and
* visually unsupported inference.

Occupation and personality inference will also be examined as specific forms of interpretive framing. Semantic shift and adjective-framing analysis will remain secondary measures because the pilot showed that semantic variation could not be statistically distinguished from normal generation stochasticity and the predefined adjective taxonomy covered only part of the observed vocabulary.

I have also documented the requirements for the final generation configuration, including the exact model identifier, API/library version, generation date, prompt, image ID, condition, repeat number, sampling parameters, maximum output tokens, API errors/retries and raw model response. The final generation script has been structured to retain these fields, although the exact model-generation parameter values will be confirmed and frozen before final data collection rather than retrospectively assumed.

### Current limitations / outstanding work

The revised annotation validation is currently single-coded. An independent person will be asked to code a small subset of cases, if possible, so that inter-rater agreement can be reported.

The final corrected experiment has not yet been generated. The methodological design and pre-scaling validation are being completed first so that the final API run is conducted only after the prompts, image set and generation configuration have been frozen.

### Next steps

The immediate next steps are to complete independent double-coding of a small annotation subset where possible, finalise and document the exact generation settings, and then run the corrected experiment using the culturally neutral main image set once API access is available. The final analysis will prioritise the predefined primary outcomes, with semantic shift and adjective analysis retained as secondary analyses.

The pilot will therefore be presented as a methodological validation stage that identified weaknesses in the original experimental design and informed the corrected final protocol, rather than as definitive evidence that geographic metadata causes bias.
