### 1. Final research question

I narrowed and locked the research question to:

> **Does geographic metadata change the probability and type of social, cultural, occupational, or personality inferences generated by a multimodal model when the same portrait image is held constant?**

This replaces the broader beauty-bias framing and makes geographic metadata the main experimental variable.

### 2. Corrected matched prompt design

I audited the original pilot prompts and confirmed that the control and country-conditioned prompts were not structurally equivalent. The country-conditioned prompts contained additional instructions, meaning that differences observed in the pilot could not confidently be attributed to the country metadata alone.

I therefore created corrected V2 prompt templates for the final experiment. The control and country-conditioned versions now use the same instructions, response structure and behavioural rules, with geographic metadata as the intended experimental difference.

I also added rendered-prompt verification in the notebook so that the actual prompt sent under each condition can be inspected before final generation.

The original pilot outputs have been retained unchanged rather than regenerated retrospectively, so the methodological limitation of the pilot remains transparent.

### 4. Image dataset screening and final decision

### 6. Audit of the original unsupported-inference measure

I revisited the original `unsupported_inference` variable and identified an important measurement problem.

The pilot variable was effectively indicating whether the model had populated one or more structured inference fields. It therefore represented the **presence of an inference**, rather than demonstrating that the inference was actually unsupported by the image.

As a result, I stopped treating this variable as evidence of visual unsupportedness and separated **inference presence** from **visually unsupported inference** in the revised methodology.

This avoids labelling an inference as unsupported without first checking it against the actual portrait.

### 7. Expanded statement-level annotation dataset

The original description outputs were segmented into **363 statement-level units**.

However, I identified that validating only description statements could bias the validation sample towards visually supported content because the description field was already constrained towards visible information.

I therefore expanded the annotation pool to include statements extracted from all relevant model-output fields:

* **363** description statements;
* **145** social/cultural inference statements;
* **69** occupation inference statements; and
* **270** personality inference statements.

This produced a larger pool of **847 candidate statements** for visual-evidence validation.

### 8. Revised visual-evidence annotation framework

I developed a stronger annotation framework to distinguish between different types of model statements.

The revised analytical categories are:

* Visible description
* Visually supported interpretation
* Metadata repetition
* Unsupported social inference
* Incorrect visual hallucination

Evidence is separately classified as:

* Supported
* Unsupported
* Uncertain

This separation is important because an inference can go beyond literal description without necessarily being a visual hallucination, while repetition of supplied metadata should not automatically be treated as a new model inference.

### 9. Completed stronger 35-case manual validation

I created a new **35-statement stratified validation sample**, drawing from different output fields rather than validating only easy descriptive statements.

I manually checked all **35/35 cases against their corresponding portrait images** and completed both the evidence labels and analytical categories.

The final evidence-label distribution is:

* **21 Supported**
* **12 Uncertain**
* **2 Unsupported**

The analytical-category distribution is:

* **10 Visible descriptions**

This improves substantially on the earlier 25-statement feasibility sample, where all sampled statements had been labelled as supported. The revised sample now includes supported, unsupported and ambiguous cases and therefore provides a more meaningful test of the annotation protocol.

### 10. Social/cultural inference refinement

I also refined the treatment of social and cultural inference in the pilot.

A total of **145 individual social/cultural claims** were extracted and classified into:

* metadata repetition;
* substantive social/cultural inference; or
* mixed claims containing both.

I manually reviewed the ambiguous cases until there were **no unresolved manual-review cases remaining**.

The final classification was:

* **89 metadata repetitions (61.4%)**
* **32 substantive inferences (22.1%)**
* **24 mixed claims (16.6%)**

This showed why simply counting the presence of content in the social/cultural field would overestimate substantive inference: a substantial proportion of the extracted claims were repetitions of metadata supplied to the model.

I therefore created a revised response-level measure for **substantive social/cultural inference** that separates genuine additional inference from simple metadata repetition.

### 11. Statistical analysis of pilot inference outcomes

I applied the revised inference measures to the pilot data and examined social/cultural, occupational and personality inference patterns.

The analysis included:

* response-level inference rates;
* image-level aggregation;
* Friedman repeated-measures tests across conditions; and
* paired country-versus-control Wilcoxon comparisons.

These analyses are retained as pilot/exploratory evidence rather than being interpreted as causal evidence of geographic-metadata effects because the original pilot prompt design contained the previously identified confound.

### 12. Repeated-generation consistency

Because each image-condition combination contains three generations, I also examined whether inference patterns were consistent across repeated outputs.

This allows the analysis to distinguish recurring patterns from observations that appear only in an individual stochastic generation.

### 13. Semantic-shift analysis and stochasticity baseline

I retained semantic shift as an exploratory analysis and compared country-conditioned outputs with their corresponding control outputs using matched image/repeat comparisons.

I also created a stochasticity baseline to determine whether apparent semantic differences between conditions were larger than the variation produced when the model generates multiple responses under the same prompt.

The pilot analysis did not provide sufficient evidence that the observed country-conditioned semantic shift was distinguishable from ordinary generation variability. For this reason, semantic shift has been retained as a **secondary outcome rather than a central claim**.

### 14. Adjective-analysis audit

I also audited the adjective-framing analysis rather than relying only on the predefined taxonomy.

The audit showed that the predefined adjective taxonomy covered only approximately **29.1% of the observed adjective tokens**.

I have therefore retained adjective analysis as a secondary/exploratory analysis and will not use it as a primary measure of geographic-metadata effects.

### 15. Primary outcomes for the final experiment

Based on the pilot findings and methodological feedback, I have now prioritised the following outcomes for the final experiment:

1. **Inference presence**
2. **Substantive social/cultural inference**
3. **Metadata repetition**
4. **Visually unsupported inference**

Occupation and personality inference will also be examined as specific forms of interpretive inference.

Semantic shift and adjective framing will remain secondary analyses.
