# Weekly Meeting Log — 29 July 2026

## Objective

To complete a reproducible pilot study investigating whether geographic prompts influence multimodal AI-generated image descriptions, and to prepare the first set of quantitative results for supervision.

---

## What I Completed This Week

- Finalised the experimental design using a controlled repeated-measures pilot.
- Built a fully reproducible analysis pipeline in Google Colab.
- Completed the pilot experiment using **Gemini 3.5 Flash**.
- Generated **150 responses** from **10 portrait images** across **five experimental conditions** (Control, Nigeria, India, Saudi Arabia and the United Kingdom), with **three repetitions per condition**.
- Structured and processed the generated responses into a single analysis dataset.
- Implemented all planned quantitative measures:
  - Semantic shift using sentence embeddings.
  - Sentiment analysis using VADER.
  - Adjective extraction and categorisation using spaCy.
  - Unsupported inference detection and coding.
- Generated descriptive statistics for each analysis measure.
- Conducted Friedman tests and pairwise Wilcoxon signed-rank tests (with Bonferroni-adjusted post-hoc comparisons where applicable).
- Produced figures illustrating:
  - Semantic shift.
  - Unsupported inference rates.
  - Adjective-category distributions.
- Selected representative qualitative examples to support the quantitative findings.
- Developed and documented a reproducible unsupported-inference coding protocol.
- Wrote and uploaded the experimental methodology documentation.
- Organised the project into a structured GitHub repository containing:
  - notebooks
  - raw and processed datasets
  - figures
  - statistical tables
  - qualitative examples
  - documentation
  - presentation slides
