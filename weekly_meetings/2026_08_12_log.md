### 7. Implemented the Stochasticity Baseline

I implemented the stochasticity baseline requested during supervision.

The purpose was to determine how much Gemini's descriptions change when the **same image and same prompt** are generated repeatedly, before interpreting country-control differences as meaningful experimental effects.

For each image, the three control generations create three same-prompt comparisons:

- repeat 1 vs repeat 2;
- repeat 1 vs repeat 3;
- repeat 2 vs repeat 3.

Across the ten images this produced:

**10 images × 3 repeat-pairs = 30 same-prompt comparisons**

The same-prompt baseline was:

- n = 30;
- mean D_same = **0.0856**;
- SD = **0.0448**;
- median = **0.0793**;
- minimum = **0.0234**;
- maximum = **0.2015**.

I then compared this intrinsic variability with country-conditioned semantic variation.

The broader country-control stochasticity comparison contained:

**10 images × 4 countries × 3 country repeats × 3 control repeats = 360 comparisons**

At image level:

| Condition | Mean D_same | Mean D_country | Mean Excess Distance |
|---|---:|---:|---:|
| Nigeria | 0.0856 | 0.1033 | 0.0177 |
| India | 0.0856 | 0.1117 | 0.0261 |
| Saudi Arabia | 0.0856 | 0.1118 | 0.0262 |
| United Kingdom | 0.0856 | 0.1155 | 0.0299 |

The country-conditioned distances were numerically larger than the same-prompt baseline.

However, I then tested the comparison at the **image level** using paired Wilcoxon signed-rank tests and Holm correction.

None of the four country comparisons remained statistically significant after correction:

| Comparison | Holm-adjusted p-value |
|---|---:|
| Nigeria vs same-prompt baseline | 0.6445 |
| India vs same-prompt baseline | 0.3926 |
| Saudi Arabia vs same-prompt baseline | 0.1484 |
| United Kingdom vs same-prompt baseline | 0.6445 |

This is an important pilot result because it shows that the observed semantic differences cannot yet be statistically distinguished from Gemini's normal generation variability.

The stochasticity baseline is therefore now a permanent component of the experimental pipeline.

### 9. Audited the Original Unsupported-Inference Variable

I revisited the original unsupported-inference measure because this was the main methodological weakness identified during supervision.

The original implementation treated a response as containing an unsupported inference when one or more of Gemini's structured inference fields contained content.

The audit showed that this variable was effectively measuring **whether a structured inference was present**, not whether that inference was actually unsupported by visual evidence.

This distinction is now explicit throughout the notebook.

I therefore stopped treating the original variable as ground truth for unsupported inference.

The original result is retained as an audit of the earlier implementation, but it is labelled as a **structured-inference proxy**.

This prevents a generated occupational, personality or cultural statement from automatically being classified as unsupported without inspecting the corresponding image.

### 10. Rebuilt the Unsupported-Inference Methodology Around Visual Evidence

I replaced the previous proxy with a statement-level visual-evidence verification protocol.

The central annotation question is now:

> **"Is this statement directly supported by visual evidence in the image?"**

Each claim can receive one of three evidence labels:

- **Supported**
- **Unsupported**
- **Uncertain**

I also separated the evidence decision from the analytical type of statement.

The five analytical categories are:

1. **Visible description** — directly observable image content.
2. **Visually supported interpretation** — cautious interpretation grounded in visible evidence.
3. **Metadata repetition** — information supplied by the prompt rather than inferred visually.
4. **Unsupported social inference** — social, cultural, religious, occupational, socioeconomic or personality information without sufficient visual evidence.
5. **Incorrect visual hallucination** — content that invents or contradicts visible image information.

This distinction is important because a statement can belong to a particular analytical category without automatically being visually unsupported.

For example, visible religious symbolism and an inference about a person's actual religion are not treated as equivalent claims.

I documented the decision rules and examples directly in the notebook so that the coding process can be critically inspected.

## Methodological Findings From the Pilot

The pilot validation identified several issues that would have affected the scientific validity of the full experiment if I had scaled the dataset immediately.

### Prompt design

The original control and country-conditioned prompts were not structurally identical.

**Resolution:** I documented the confound, revised the interpretation of the existing results, and defined structurally matched prompts as a requirement before scaling.

### Image selection

One pilot portrait was identified as potentially culturally diagnostic.

**Resolution:** I formalised the screening criteria and defined stricter culturally neutral selection for the primary full-scale dataset.

### Unsupported-inference definition

The original proxy measured structured inference presence rather than visual unsupportedness.

**Resolution:** I replaced it with a statement/atomic-claim visual-evidence verification protocol.

### Metadata repetition

A large proportion of social/cultural outputs repeated information already supplied in the prompt.

**Resolution:** I separated metadata repetition, substantive inference and mixed claims before analysis.

### Model stochasticity

Semantic differences can occur even when the image and prompt remain unchanged.

**Resolution:** I implemented a same-prompt stochasticity baseline and compared experimental differences against normal generation variability.

### Statistical independence

The 150 responses are not 150 independent experimental units.

**Resolution:** I aggregate repeated generations at image level before inferential testing.

### Annotation granularity

Some extracted sentences contain multiple independently assessable claims.

**Resolution:** I added atomic-claim decomposition to the final annotation procedure.

### Annotation reliability

The current protocol validation uses one coder.

**Resolution:** I explicitly treat the 25-statement exercise as protocol validation rather than inter-rater validation. Independent double-coding is required before the final large-scale unsupported-inference analysis.

### Generation configuration

Not all sampling parameters from the original pilot were recorded explicitly.

**Resolution:** I documented this limitation without inventing historical values. The complete generation configuration will be frozen before scaled data collection.
