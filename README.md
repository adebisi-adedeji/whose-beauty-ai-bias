## Project Overview

This repository contains the experimental pipeline and pilot analysis developed for my MSc Data Science dissertation investigating how geographic context can influence multimodal AI-generated descriptions of the same portrait image.

The study examines whether changing the supplied country context alters the probability or type of social, cultural, occupational, personality, and appearance-related inferences generated by a multimodal model while the underlying portrait remains fixed.

The repository documents both the empirical pilot results and the methodological development of the study. Importantly, the pilot was used not only to obtain preliminary results, but also to identify limitations in the original experimental design and establish a more defensible framework for future scaled evaluation.

---

## Research Question

> **Does geographic metadata change the probability and type of social, cultural, occupational, or personality inferences generated by a multimodal model when the same portrait image is held constant?**

## Pilot Experimental Design

The completed pilot consists of:

| Component | Pilot configuration |
|---|---|
| Model | Gemini multimodal model |
| Portrait images | 10 |
| Conditions | Control, Nigeria, India, Saudi Arabia, United Kingdom |
| Repeated generations | 3 per image-condition |
| Expected responses | 150 |
| Responses obtained | 150 |
| Primary experimental unit | Image |

The three generations within each image-condition combination are treated as repeated stochastic observations rather than independent samples. Where appropriate, repeated generations are therefore aggregated at image level before inferential testing.

During subsequent image screening, **9 portraits were retained as the culturally neutral primary-analysis subset**, while **1 borderline portrait was separated for sensitivity/robustness consideration**.

## Analytical Framework

### 1. Structured inference analysis

The model responses contain structured fields for:

- social or cultural inference;
- occupation inference;
- personality inference.

The analysis evaluates how frequently these fields are populated across experimental conditions.

Crucially, **inference presence is not treated as equivalent to visually unsupported inference**. Whether a statement is unsupported requires separate assessment against the source image.

### 2. Social and cultural claim classification

Social and cultural claims are separated into:

- **metadata repetition** — restating or directly incorporating supplied contextual metadata;
- **substantive inference** — introducing an additional social or cultural interpretation;
- **mixed** — containing both metadata repetition and additional inference.

This distinction prevents simple repetition of the supplied country information from automatically being interpreted as an unsupported model inference.

### 3. Visual-evidence annotation

Generated statements are evaluated separately according to whether they are supported by visible evidence.

The annotation framework distinguishes:

- visible description;
- visually supported interpretation;
- metadata repetition;
- unsupported social inference;
- incorrect visual hallucination.

A statement-level validation subset was manually reviewed during the pilot. This is treated as a **methodological feasibility check rather than an estimate of unsupported-inference prevalence across the complete statement dataset**.

### 4. Semantic shift

Sentence embeddings and cosine distance are used to measure how much country-conditioned descriptions differ semantically from corresponding control descriptions.

Because multimodal language models can produce different responses to the same prompt, semantic differences are interpreted alongside a repeated-generation stochasticity baseline.

### 5. Stochasticity baseline

Repeated control generations are compared to estimate normal same-prompt generation variability.

The mean same-prompt semantic distance in the pilot was approximately **0.0856**, while mean country-to-control distances were approximately **0.103–0.116**.

The pilot analysis did not find corrected country comparisons that clearly exceeded the stochasticity baseline.

### 6. Adjective framing

Appearance adjectives are extracted and evaluated using a predefined taxonomy containing dimensions including:

- appearance;
- professionalism/competence;
- warmth;
- modernity/traditionalism;
- socioeconomic framing.

The pilot produced **74 unique observed adjectives and 711 adjective tokens**. The fixed taxonomy captured **207 of 711 tokens (29.1%)**, illustrating both the usefulness and limitations of predefined lexical categories.

## Statistical Analysis

The study uses a repeated-measures design because every portrait is evaluated under every experimental condition.

The statistical workflow includes:

- image-level aggregation of repeated generations;
- Friedman tests for repeated-measures comparisons;
- Kendall's W as an effect-size measure;
- Wilcoxon signed-rank tests for paired follow-up comparisons where appropriate;
- correction for multiple comparisons.

The pilot sample is small and is therefore interpreted primarily as **methodological and exploratory evidence**, rather than as definitive population-level hypothesis testing.

## Key Pilot Observations

The pilot demonstrates that model outputs can vary substantially across experimental prompt conditions, particularly in structured occupation, personality, and social/cultural inference fields.

It also demonstrates why several apparently similar concepts must be kept analytically separate:

> **inference presence ≠ substantive inference ≠ visually unsupported inference**

This distinction became a central methodological outcome of the pilot.

The pilot additionally showed that:

- semantic differences between conditions were relatively small compared with normal generation variability;
- adjective framing varied descriptively across conditions, but the tested adjective dimensions did not remain statistically significant after multiple-testing correction;
- metadata repetition accounted for a substantial proportion of extracted social/cultural claims;
- visual-evidence assessment is necessary before describing an inference as unsupported.

These findings are interpreted cautiously because the pilot contains only ten portraits and because the original control and country-conditioned prompt templates were not perfectly matched.

---

## Important Pilot Limitation

An audit of the original prompts found that the control and country-conditioned templates differed by more than the country metadata itself.

Consequently, the pilot **cannot isolate geographic metadata as the sole causal explanation for differences between conditions**.

Rather than retrospectively changing the original experiment, the pilot responses have been retained unchanged and this limitation is documented explicitly.

The corrected experimental design uses structurally matched prompts so that geographic metadata can be isolated more cleanly in future scaled evaluation.

## Scope and Interpretation

This repository documents a **pilot study and methodological validation exercise**.

The results should not be interpreted as establishing general behaviour across all multimodal models, countries, demographic groups, or portrait images. The sample contains ten pilot portraits and evaluates a single multimodal-model workflow.

The strongest contribution of the pilot is therefore methodological: it identifies several ways in which geographic-context effects can be incorrectly measured and develops a framework that separates prompt effects, metadata repetition, substantive inference and visual support.
